# הרכב שלי – פיג׳ו 3008 (2019)

PWA לניהול הרכב: מה דחוף, יומן תדלוקים, טיפולים ותיקונים, טסט ורישיון, ומסמכים.
הממשק בעברית ומימין לשמאל, עם מצב בהיר ומצב כהה. הנתונים מסונכרנים בין הטלפון למחשב (Firebase) ונשמרים גם ללא חיבור לאינטרנט.

**הקמה:** ראה [SETUP.md](SETUP.md).

## טכנולוגיות
React 19 + TypeScript + Vite + Tailwind CSS · Firebase Auth (Google) + Firestore (offline cache) · vite-plugin-pwa · GitHub Pages.

## מבנה
- `src/lib/calc.ts` – צריכת דלק, זיהוי חריגות, הערכת ק״מ, תחזית טיפול ולוח "מה דחוף"
- `src/lib/validation.ts` – בדיקות סבירות לתדלוקים, מניעת כפילות טסטים, וחסימת מידע רגיש
- `src/lib/backend.ts` – שכבת אחסון (Firestore או localStorage)
- `src/pages/*` – המסכים

## כללי פרטיות
- כל מחיקה דורשת אישור מפורש.
- האפליקציה חוסמת שמירה של מספרי ת״ז, כרטיסי אשראי, פרטי חשבון בנק וכתובת מגורים.

## שלבים הבאים
1. חלקים שמתבלים (מצבר, 5 צמיגים כולל רזרבי, רפידות, מגבים) עם עדכון אוטומטי מהטיפולים
2. השוואת הצעות לחידוש ביטוח
3. הוצאות נוספות (חניה, כביש 6, דוחות, שטיפות) וסיכום עלות שנתית
4. ציוד ברכב לפי מיקום, עם תוקף ורשימת קניות לשיתוף
5. העלאת קבצים ל-Google Drive, סנכרון ל-Google Calendar וייבוא חודשי מ-Gmail
